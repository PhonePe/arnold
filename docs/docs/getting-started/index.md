# Getting started

Arnold has three deployable parts and two data stores. To try it, the [quick start](quick-start.md) runs all of
them on your machine with Docker Compose. Read [Architecture](architecture.md) to see how they connect, and
[Concepts](concepts.md) for the terms used in the rest of these docs.

The usual order:

1. **[Quick start](quick-start.md)**: bring up the stack with development sign-in.
2. **Connect a forge**: [GitHub App](../setup/github-app.md) and/or [GitLab](../setup/gitlab.md).
3. **Choose a model**: [LLM and harnesses](../setup/llm.md).
4. **Run your first review**: [Run analysis](../features/run-analysis.md).
5. **Before others use it**: [Sign-in](../setup/sign-in.md) and [Production deployment](../setup/production.md).
