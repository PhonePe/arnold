# Bundled fonts

These unmodified fonts are loaded by `next/font/local` so builds do not fetch Google Fonts.

- [Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk): `SpaceGrotesk[wght].ttf`, saved as `space-grotesk/SpaceGrotesk.ttf`; variable weight, used at 400–700.
- [IBM Plex Mono](https://github.com/google/fonts/tree/main/ofl/ibmplexmono): regular (400), medium (500), and semibold (600).

Downloaded from the Google Fonts repository on 2026-09-08. Full character sets are retained.
Each family includes its original SIL Open Font License in `OFL.txt`; the Docker image also copies these licenses to `/app/licenses/`.
